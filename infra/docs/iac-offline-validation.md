# Offline validation

**DEPLOYMENT AND EVIDENCE NOT RUN — author + offline dry-run only.**

All commands below use only this tree and localhost. No real host secrets are
needed and no SSH/VM target is contacted. Container images are not pulled.

## Tool versions used

- Python 3.13
- ansible-core **2.18.20**
- ansible-lint **25.12.2**
- yamllint **1.38.0**
- Docker Compose **v2.40.3** (standalone validation binary, no daemon)
- Jinja2 (ansible-core dependency), PyYAML, jsonschema for structural checks
- community.docker 5.4.0, community.libvirt 2.4.0, ansible.posix 2.2.2

Install them in an isolated venv (inside the team workspace, but never ship
`.venv` or `.collections`):

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install 'jsonschema>=4,<5'
.venv/bin/ansible-galaxy collection install -r requirements.yml \
  -p .collections
export PATH="$PWD/.venv/bin:$PATH"
export ANSIBLE_COLLECTIONS_PATH="$PWD/.collections"
```

The Compose standalone binary may already be on PATH as `docker-compose`; set
`COMPOSE=docker-compose`, or download the v2.40.3 release separately to a
scratch directory and set `COMPOSE=/absolute/path/to/docker-compose`.
A Docker daemon is unnecessary. The fallback is the included JSON-schema check;
`tests/compose-spec.json` is vendored so that fallback is fully offline.

## Exact checks (run from `infra/`)

```sh
ansible-playbook -i inventory/local-dry-run.yml site.yml --syntax-check
yamllint -c .yamllint.yml site.yml teardown.yml requirements.yml \
  group_vars inventory roles host_vars
ansible-lint -c .ansible-lint site.yml teardown.yml
ansible-playbook -i inventory/local-dry-run.yml site.yml --check --diff
python scripts/render-compose.py
python tests/validate_rendered.py
python tests/validate_compose_schema.py
"$COMPOSE" -f rendered/open5gs_epc_cups/docker-compose.yml config --quiet
"$COMPOSE" -f rendered/ran_srsran/docker-compose-ran.yml config --quiet
bash scripts/secret-scan.sh
```

Before RAN Compose validation, use the placeholder `ran.env` generated by the
render script (values are deliberately zero and not valid subscriber secrets).
If `.env`/`.venv` is present, yamllint must be scoped to the authored paths as
above rather than accidentally linting the virtualenv or collections.
