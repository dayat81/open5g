# gost binary (not shipped)

This directory is the expected location of `gost` (linux/amd64). The binary is
**not** included in the repository.

Install **gost 3.3.3** and place the executable at `inet/bin/gost`. Full
commands, official tarball checksum, and the lab-tested binary SHA-256 are in
[`../README.md`](../README.md#gost).
